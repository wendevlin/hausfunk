# Brand

A roof over a radio wave over a dot: a house (*Haus*) sending a signal (*Funk*) from what matters
inside it.

![Preview](preview.png)

| File | Use |
| --- | --- |
| `app-icon.svg` | app icon, mark on a navy tile |
| `logo-mark.svg` | mark alone, for light backgrounds |
| `logo-mark-dark.svg` | mark alone, for dark backgrounds |
| `logo-lockup.svg` | mark + wordmark, for light backgrounds |
| `logo-lockup-dark.svg` | mark + wordmark, for dark backgrounds |

The wordmark is Inter Display Medium (SIL OFL), converted to outlines, so the files need no font.

| Colour | Hex | Role |
| --- | --- | --- |
| Navy | `#203563` | roof, wordmark, dark background |
| Steel | `#557691` | wave |
| Sand | `#EED1AF` | roof and wordmark on dark, light background |
| Amber | `#FFC46F` | the dot; accent only |
